# coderzonebd/homebrew-tap

Homebrew casks for [Whoosh Download Manager](https://github.com/coderzonebd/whoosh-download-manager).

```bash
brew install --cask coderzonebd/tap/whoosh-download-manager
```

The cask is updated automatically on every release. The app keeps itself up to date and tells
Homebrew so (`auto_updates true`).
